# Partner Overview – optional starter

A small Vite + React + TypeScript project with the case data already loaded. Use it if it saves you
time, or use any other stack.

## Run it

You need Node.js 20 or later.

```bash
npm install
npm run dev
```

Run `git init` and commit the starter as it is before you begin, so your own changes are easy to see.

## What's here

| Path | What it is |
| --- | --- |
| `src/data/partner-overview-data.json` | Sara's data. Field meanings are in the brief and in `definitions` inside the file. |
| `src/data/types.ts` | TypeScript types for the data. |
| `src/data/load.ts` | Imports the data as a typed object. |
| `src/styles/tokens.css` | Tokens as CSS custom properties. Meant to mirror the Figma collection "tokens (WIP)", but like the Figma file it hasn't been kept tidy. |
| `src/components/BrandTable.tsx` | An empty component where your table goes. |
